# JobMatch ATS - Otimizador de Currículos Inteligente 🚀

> Projeto desenvolvido como MVP para ajudar candidatos a superarem os filtros automáticos de recrutamento (ATS) sem inventar experiências.

## 📌 O Problema Resolvido
Muitos profissionais qualificados são eliminados dos processos seletivos antes mesmo de um recrutador ler seus currículos, porque os sistemas ATS barram arquivos mal formatados ou sem as palavras-chave da vaga. Este aplicativo resolve isso comparando o currículo à vaga e gerando uma versão otimizada.
